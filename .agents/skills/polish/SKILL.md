# Polish

Use this skill when the user asks to "polish", "refine", or elevate the visual quality of an existing UI component, page, or flow before shipping.

> **Principle**: Polish is refinement, never concealed redesign. Preserve the incumbent visual identity, behavior, content, and scope while eliminating inconsistencies.

## Workflow

1. **Establish the system**: Read `DESIGN.md` or existing tokens, layout patterns, and conventions.
2. **Gather evidence**: Inspect the interface across desktop and mobile breakpoints.
3. **Triage defects**:
   - Fix functional & accessibility defects (contrast, focus, missing states).
   - Resolve flow, hierarchy, responsive, and token drift.
   - Refine micro-interactions, motion, and visual rhythm.
   - Clean up code and styles.
4. **Preserve restraint**: Do not over-polish or add unnecessary decoration.
